# GitHub 上传说明

## 先确认用途

当前版本适合个人在本地使用，也支持多个邮箱账号使用各自独立的工作台。GitHub 仓库可以公开，但 `.env` 和个人数据不能上传。

## 推荐做法

1. GitHub 仓库名使用 `ai-product-workbench`。
2. 使用 GitHub Desktop，选择“添加现有仓库”。
3. 选择桌面上的“个人产品工作台”文件夹。
4. 上传前先用 `git status` 确认没有 `.env`、密钥和个人资料。

## 不会上传的内容

仓库忽略规则会排除：

- `.env` 和其他本地环境配置
- `node_modules`
- 编译结果和缓存
- 数据库文件、数据库备份和本地上传文件
- 飞书 `.base` 原始资料

Docker 数据卷不在项目文件夹中，因此个人事项不会跟随代码上传。

## 公开上线前仍需完成

- 关闭本机测试验证码：`WORKBENCH_DEV_LOGIN_CODE=0`
- 配置正式邮件服务，让验证码发送到用户邮箱
- 配置正式域名、HTTPS、数据库备份和安全密钥
- 配置 AI 服务密钥和使用额度限制
- 上线前再进行一次完整的权限与安全测试

在这些工作完成前，不要把本地端口直接暴露到互联网。
