# GitHub 上传说明

## 先确认用途

当前版本适合个人在本地使用，也适合放到 GitHub 私有仓库做代码备份。它还不是可以直接公开上线的多人产品。

## 推荐做法

1. 在 GitHub 新建一个私有仓库，仓库名建议使用 `personal-product-workbench`。
2. 使用 GitHub Desktop，选择“添加现有仓库”。
3. 选择桌面上的“个人产品工作台”文件夹。
4. 发布仓库时确认勾选“保持此代码私有”。

## 不会上传的内容

仓库忽略规则会排除：

- `.env` 和其他本地环境配置
- `node_modules`
- 编译结果和缓存
- 数据库文件、数据库备份和本地上传文件
- 飞书 `.base` 原始资料

Docker 数据卷不在项目文件夹中，因此个人事项不会跟随代码上传。

## 公开上线前仍需完成

- 关闭本地单人自动登录模式
- 为每个账号创建独立工作台，并验证所有数据接口的用户隔离
- 配置正式域名、HTTPS、数据库备份和安全密钥
- 配置 AI 服务密钥和使用额度限制
- 进行完整的权限与安全测试

在这些工作完成前，不要把本地端口直接暴露到互联网。
